discord-newsbot

A Discord bot that reads the news for the games your server follows every morning so nobody has to, and can announce new Borderlands 4 SHiFT codes when one turns up, with what each code unlocks and when it expires.

Add to Discord

Getting started

  1. Add it. Click the button and pick your server. You need the Manage Server permission there; Discord won't list servers where you don't have it.
  2. Set it up. Run /newsbot setup. It asks for your time zone, the time you want the daily digest, the games you follow, and the channel to post in. There's also a "Gaming industry" option for news that isn't about any one game: studios closing, layoffs, big announcements. It posts up to five stories a day. Run it again any time to change your answers.
  3. SHiFT codes (optional). Run /newsbot shift to turn on Borderlands 4 code alerts, pick their channel, and decide whether they ping a role, everyone, or nobody. Nobody is the default. If you pick a ping, the bot tells you the one extra permission it needs.

After that, members can use /news recent and /news search for the stored headlines, and /shift codes for the SHiFT codes that should still work.

What it costs

Nothing. Every server gets a headline digest for each game it follows, plus SHiFT alerts if they're turned on. No AI is involved in a game's digest. If your server turns on Gaming industry, an AI picks which headlines it shows, and the headlines are still the sources' own words. Nothing about your members is collected beyond what the privacy policy describes. If you'd rather run a copy of your own, the source code explains how.
